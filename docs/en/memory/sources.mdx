---
title: Agent 来源与扫描
description: Codex 与 Claude Code 的历史扫描、Hook 和 Skill。
---

| Agent | 默认历史来源 | 实时接入 |
| --- | --- | --- |
| Claude Code | `~/.claude/projects/**/*.jsonl` | Hook + `memmy-memory` Skill |
| Codex | `~/.codex/sessions/<YYYY>/<MM>/<DD>/rollout-*.jsonl` | Hook + `memmy-memory` Skill |

可以分别使用 `CLAUDE_CONFIG_DIR` 和 `CODEX_HOME` 覆盖默认目录。

**同步新增**只处理水位之后新增或尚未完成的会话；**深度扫描**用于回扫旧历史。失败或不完整回合不会推进水位，以便下一次安全重试。

安装后，Hook 会在请求前召回相关记忆，在回合完成后采集用户请求、Assistant 回复和工具轨迹。失败采用 fail-open，不阻断当前 Codex 或 Claude Code 任务。
